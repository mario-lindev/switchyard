# Switchyard design system

## World

A bright engineering instrument: paper-white workspace, graphite navigation, vermilion action color, green healthy telemetry, precise hairlines. An operations tool used in a well-lit engineering workspace.

## Typography

Self-hosted DM Sans variable for UI; JetBrains Mono for code and measured values. Body 16px; secondary metadata 12–13px. Headings use tight but natural tracking.

## Tokens

Canvas #f6f7f9; surface #ffffff; sidebar #171b23; ink #202631; muted #69717f; line #e5e8ed; accent #e65e36; positive #218564; warning #b47d1c; danger #d54e4e. Border radius 8px controls, 12px panels. 4px spacing base.

## Surface: Release lab

Mode: Operate. First viewport shows a real interactive service topology, active feature flags, and a useful run action. A light, spatially generous topology is the signature. The signature interaction is failure propagation: animated requests switch to red along affected edges, service telemetry reacts, and a rollback returns routes to healthy state. The controls remain usable without motion. Synthetic data is labeled in the top-level toolbar and evidence.

## Responsive

Desktop rail and split topology/flags panel; medium condensed rail; mobile stacked workspace and horizontal navigation. No task-critical content depends on hover.
